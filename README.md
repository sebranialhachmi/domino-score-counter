# حاسبة نقاط الدومينو (Domino Scoreboard)

تطبيق ويب لحساب نقاط لعبة الدومينو بين فريقين، بسمة داكنة هادئة وعالية التباين، مصمم أولاً للهواتف ويدعم العربية واتجاه RTL.

## المزايا

- **كروت نقاط زجاجية:** المجموع والهدف (مثل `142 /200`) بخط عريض كبير، شريط تقدم متحرك، النقاط المتبقية، وشارة "متقدم" فوق الفريق المتصدر.
- **لوحة أرقام مخصصة:** لا تظهر لوحة مفاتيح النظام أثناء اللعب. أزرار كبيرة، اختيار الفريق بلمسة، وأزرار سريعة `+10` و`+25` و`+50` بجانب زر "أضف نقاط".
- **سجل جولات قابل للتمرير:** رقم واضح لكل جولة مع المجموع التراكمي. اسحب الجولة (أو المسها) لإظهار "تعديل" و"حذف"، مع إمكانية التراجع عن الحذف.
- **إعلان الفائز:** شاشة احتفالية مع خيار "بدء لعبة جديدة".
- **حفظ تلقائي** في المتصفح، ودعم لوحة المفاتيح الفعلية على الحاسوب (الأرقام، Backspace، Enter، Tab لتبديل الفريق).

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
```

## بنية الملفات

```
src/
  App.jsx                  حالة اللعبة وتخطيط الشاشة
  lib/game.js              الحساب، تحديد الفائز، والحفظ
  components/
    ScoreCards.jsx         كروت النقاط والتقدم
    RoundHistory.jsx       سجل الجولات
    SwipeRow.jsx           إيماءة السحب لإظهار الإجراءات
    Keypad.jsx             لوحة الأرقام والأزرار السريعة
    SetupScreen.jsx        إعداد الفرق والهدف
    WinnerModal.jsx        شاشة الفوز
    Toast.jsx, Icon.jsx, teamStyles.js
```
