# حاسبة نقاط الدومينو (Domino Scoreboard)

تطبيق ويب لحساب نقاط لعبة الدومينو بين فريقين، مصمم للهواتف الذكية ويدعم العربية واتجاه RTL.

## المزايا

- **إعداد اللعبة:** أسماء الفريقين وحد النقاط للفوز (100 / 150 / 200 / 500 أو رقم مخصص).
- **الشاشة الرئيسية:** مجموع كل فريق بخط كبير مع شريط تقدم والنقاط المتبقية، وإدخال سريع لنقاط الجولة.
- **سجل الجولات:** جدول بكل الجولات مع المجموع التراكمي، وإمكانية تعديل أو حذف أي جولة.
- **إعلان الفائز:** شاشة احتفالية مع قصاصات ملونة وخيار "بدء لعبة جديدة".
- **حفظ تلقائي:** تُحفظ اللعبة في المتصفح (localStorage) فلا تضيع عند إعادة تحميل الصفحة.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
```

## التقنيات

React 18 + Vite + Tailwind CSS v4.
