# Domino Apunte free — حاسبة دومينو مجانية

تطبيق ويب مجاني لحساب نقاط لعبة الدومينو بين فريقين، بسمة داكنة هادئة وعالية التباين، مصمم أولاً للهواتف، ويدعم العربية (RTL) والإنجليزية والفرنسية.

## الشاشات

| الشاشة | المحتوى |
| --- | --- |
| **اللعبة** | كروت نقاط زجاجية (المجموع/الهدف، شريط تقدم، شارة "متقدم")، سجل جولات بالسحب للتعديل والحذف، ولوحة أرقام مخصصة مع `+10` و`+25` و`+50`. |
| **المحفوظة** | كل مباراة تُحفظ تلقائياً. بحث باسم الفريق، فلترة (الكل / مكتملة / غير مكتملة)، وتفاصيل كل مباراة: التاريخ، المدة، أداء الفريقين، والجولات. يمكن متابعة مباراة غير مكتملة أو بدء مباراة جديدة بنفس الفرق. |
| **الإحصائيات** | عدد المباريات والجولات، متوسط نقاط الجولة، أبرز الأرقام (أعلى جولة، أكبر فارق فوز، أطول مباراة، متوسط المدة)، وترتيب الفرق حسب الفوز. |
| **الإعدادات** | اللغة (العربية / English / Français)، السمة (كحلي / أسود)، الأصوات، الاهتزاز، إبقاء الشاشة مضاءة أثناء اللعب، وإدارة البيانات. |

كل البيانات محفوظة على الجهاز فقط (localStorage).

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
```

## بنية الملفات

```
src/
  App.jsx                     التنقل بين الشاشات، اللعبة الحالية، ومزامنة المحفوظة
  i18n/strings.js             نصوص الواجهة بالعربية والإنجليزية والفرنسية
  lib/
    game.js                   الحساب، الفائز، الحفظ، ملخص المباراة والإحصائيات
    prefs.jsx                 الإعدادات، الترجمة t()، الأصوات والاهتزاز، قفل الشاشة
    sound.js                  مؤثرات صوتية مولّدة بـ Web Audio
  screens/
    GameScreen.jsx            شاشة اللعب
    SavedGamesScreen.jsx      الألعاب المحفوظة
    GameDetailsScreen.jsx     تفاصيل المباراة
    StatsScreen.jsx           الإحصائيات
    SettingsScreen.jsx        الإعدادات واللغة
  components/
    ScoreCards, RoundHistory, SwipeRow, Keypad, SetupScreen,
    WinnerModal, TabBar, ScreenHeader, Toggle, Toast, Icon
```
